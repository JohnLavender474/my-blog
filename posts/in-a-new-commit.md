While working on a personal project, I asked Opus 5.5 to add some dummy data to a list in order to test out a UI element live. It said that it would "run git revert on the commit in order to remove the dummy data". 

Later on, when it was time to remove the dummy data, I instructed it while in Auto Mode with the following verbatim: "Remove the dummy data in a new commit." 

I guess my instruction "in a new commit" was ambiguous? It proceeded to run "git revert" which is not what I wanted, so I stopped it and re-instructed with much more verbosity. 

Why am I rambling about this seemingly banal experience? Because to me it just illuminates a wide gap that's yet to be filled by current tech. For as crazy and awesome as it is to be able to speak with and give instructions like this to a software, the alignment between intention and action still isn't one to one yet.
